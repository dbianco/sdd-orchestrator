# Kiro pack

Templates written for this project in Kiro's three-document structure
(requirements, design, tasks) using EARS notation. No proprietary Kiro text is
copied. Kiro is routed only by policy or explicit preference (spec section
8.2) because its workflow assumes the Kiro IDE.

`pack.yaml` deliberately carries no `source_url`. Kiro's documentation at
`kiro.dev/docs/specs/` is AWS-proprietary; pairing that URL with `license: MIT`
on every ingested row would read, to a licence audit of the database, as an MIT
claim over proprietary source material. `license: MIT` covers the originals in
this directory, which is all that is ingested.
